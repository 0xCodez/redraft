Privacy

It only touches what you point it at.

One tab at a time

It runs only on the tab where you click it, and has no access to your other pages.

Forms stay private

Form values are never read and password fields are skipped. Emails, long numbers and tokens are masked.

Your Claude, your machine

It runs on the Claude Code already on your computer, with no API key, no new account and no server in the middle.

Agents can't touch your files

Page text can try to steer a model, so Claude Code runs with every tool off. Edits are limited to styling.

Redraft sends the page's visible text and styles to Claude. Avoid running it on pages you wouldn't paste into a chat.

Install

Running in two minutes.

Free and open source. It's not on the Chrome Web Store yet, so it installs from a folder. View the code on GitHub

  1. Step 1

    Download

    A ready folder with the extension and the Claude Code bridge. Unzip it somewhere permanent.

    Download Redraft
  2. Step 2

    Load it in Chrome

    Open chrome://extensions, turn on Developer mode, click Load unpacked and choose the extension folder.

  3. Step 3

    Connect Claude

    node ~/Downloads/Redraft/bridge/connect.mjs

    Run this once in Terminal with Claude Code installed. Without it, or on Windows, paste an API key in Redraft settings.

FAQ

Good questions.

Does it change the real website?

No. Edits live in your browser tab, and a reload brings the original back. Use Copy CSS to keep a redesign.

Can I redesign a site in my own brand style?

Yes. Save your style once, by copying it from your site or building it in the editor. Claude then works strictly inside it and adds no colors or fonts of its own.

Is it open source?

Yes, under the MIT license. The code is on GitHub.

Do I need an API key?

No, if Claude Code is installed and you are logged in. Redraft talks to it through a small local bridge. An API key is the alternative for computers without Claude Code.

How much does a redesign cost?

With Claude Code it uses your plan's normal limits. With an API key you pay Anthropic directly, and the bar on the page shows tokens as they are used.

Can agents rewrite the text?

Only if you tick the box. By default they change styling and leave your words alone.

Will it work on every site?

Most. Agents change CSS rather than restructure HTML, sites that re-render constantly can overwrite edits, and browser pages like chrome:// are off limits.
